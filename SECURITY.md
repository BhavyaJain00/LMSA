# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of LearnLoop seriously. If you believe you have discovered a vulnerability, please do NOT file a public issue.

Instead, please report vulnerabilities by contacting our security team via email at `security@learnloop.local` or opening a private advisory on GitHub.

### When reporting:
1. Provide a clear description of the potential vulnerability.
2. Include reproduction steps or proof-of-concept code where possible.
3. Allow reasonable time for remediation before any public disclosure.

We strive to respond to security reports within 48 hours and work expeditiously toward a resolution.
